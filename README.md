## 项目

### 🎮 number_guessing.py · 猜数字游戏

程序随机生成一个数字，玩家通过提示（大了/小了）猜出它。
支持自定义范围，并用 JSON 持久化保存历史最高纪录。

```bash
python number_guessing.py
```

**技术点：** 文件读写 · JSON 持久化 · 异常处理 · 输入校验

**开发历程：**
- 2026-09-21 最初的猜数字 → 重命名为 `number_guessing.py`
- 2026-09-23 加入成绩记录与读取功能，统一文件名
- 2026-09-25 增加历史最高纪录显示
- 2026-10-08 修复输入校验：**输错不消耗猜测次数**

> 这个项目记录了从"能跑"到"好用"的过程 —— 每个提交都在解决一个真实的使用问题。
